*batch.nvim*

batch.nvim                                                *batch.nvim*

Neovim support for long Windows Batch files. It extends the native `dosbatch`
filetype with label indexing, navigation, structural diagnostics, folding,
completion, and a statusline component.

COMMANDS                                                    *batch-commands*

:BatchCheck              Rebuild diagnostics for the current buffer.
:BatchJumpToLabel        Select a label and jump to it.
:BatchJumpToLabel name   Jump directly to a label.
:BatchReferences         List references to the current target.
:BatchOutline            Open the label outline.
:BatchPeek               Peek at a Batch target or expand a config variable.

SETUP                                                        *batch-setup*

The plugin sets up automatically when loaded. With lazy.nvim:

  {
    "iamcheyan/batch.nvim",
    ft = { "dosbatch", "batch", "dosini", "conf", "sh" },
    opts = {},
  }

Buffer-local `K` and `zp` peek mappings are enabled by default and controlled
by `enable_peek`. In Batch buffers they preview variables, labels, and files.
In `.conf` buffers (including those Neovim detects as `sh`) they recursively
expand `KEY=VALUE` entries.
Set `map_keys` to true if buffer-local `gd` and `gr` mappings are desired.

CONFIG VARIABLE EXPANSION                                  *batch-config-peek*

Open a `.conf` file, place the cursor on an assignment line, and press `K` or
`zp`. The floating preview shows the final value, expansion chain, and source
location. When the cursor is on an explicit variable reference, that referenced
variable is expanded instead. Supported forms are `%NAME%` and `!NAME!` for
Batch, and `${NAME}` for Shell-style configuration. Shell references are
case-sensitive; Batch references are case-insensitive.

Expansion is static. The plugin does not source or execute the configuration.
Undefined references remain in the displayed value and are listed as
unresolved; cyclic references are detected and stop expanding.

STATUSLINE                                                  *batch-statusline*

Use `require("batch.statusline").component()` with lualine, Heirline, or a
custom statusline implementation.

LIMITATIONS                                                  *batch-limitations*

The plugin does not execute cmd.exe or a Shell. It does not model every
percent-expansion, delayed-expansion, quoting, or command-substitution rule.
